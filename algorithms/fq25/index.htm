This is a temporary placeholder page. This will eventually link to files from my Fall 2025 undergraduate algorithms course, along with more detailed explanations for how these were used and other features for the quarter.
This is not my most recent offering of the course, so for the most current version of the class, please see the top level folder. UC Irvine is on a quarter system; this is a ten-week class. The prerequisites are two quarters of discrete math, data structures, and calculus.

Lecture Handouts

For the first few lectures, I provided smaller handouts; as we progressed later in the quarter, I provided handouts for the full units.
  • 01-02: Review of Proofs
  • 01-03: Concurrent Min and Max, covering the algorithm that finds both
  • Unit 1 : the first unit of the class covers divide and conquer algorithms and also some graph modeling/layering. These topics are touched on in prerequisite courses. The Master Theorem is covered in a discussion section.
  • Unit 2: Dynamic Programming : the second unit
  • Unit 2: Dynamic Programming (Addendum) : an addition to the second unit
  • Unit 3: Greedy Algorithms : the third unit. A point of emphasis here is proofs of correctness.
  • Unit 4: Network Flow : the fourth unit. A point of emphasis here is reductions, using network flow to solve problems, with less of a focus on being able to perform calculations by hand.

Problem Sets

These are homework assignments, organized by units. These are assigned, but not collected for credit. Solutions are provided to students during the quarter.
  • Problem Set 1, covering divide and conquer algorithms and some graph modeling.
  • Problem Set 2, covering dynamic programming.
    • Problem Set 2 Precursor, reviewing recursion. These are problems I have given in past offerings of the data structures prerequisite.
  • Problem Set 3, covering greedy algorithms and their proofs of correctness.
  • Problem Set 4, covering network flow and using such an algorithm to solve problems

Diagnostic (Practice) Exams

These are in the same format as the real exams students will take. As with problem sets, these are not collected for credit (the real exams are, of course), and solutions are provided to students during the quarter. In this quarter, each unit had a separate unit test, for which students had a base time of 40 minutes from start to end.
